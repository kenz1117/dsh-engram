记忆星河视图

新视图大型

在「走廊」之外开一个全新的鸟瞰视图：把全部记忆按主题簇排成星座， 亮度 = 重要性，星等 = 访问频率，连线 = 语义近邻。 用来一眼识别冷宫区与活跃簇，比 5 间房颜色更深一层。

实现：服务端按 engram_search room 主题 + k-means 5 簇分组返回节点，前端用 force / canvas 渲染。 hover 单星弹出门牌 + 来源；点击簇中心平移到该主题的「陈展」过滤态。

03

信念星云

信念视图升级实体相关

把现有「信念」视图从扁平列表升级为引力体可视化：核心信念 = 恒星， 证据 = 行星，证据与信念用引力线相连，证据数越多线越粗。 比纯 list 更直观地感受「这条信念站得多稳」。

实现：服务端 GET /api/engram/observation-evidence 已能拿证据， 前端按 evidence_count 排序，取前 5 条做引力图，剩余 list 保留。

05

画像 KPI · sparkline 趋势

今日视图小改动

给「今日速览」三个主 KPI（记忆 / 开放 / 清晰度）每个加一条 30 天 sparkline， 一眼看出总库在涨、清晰度在掉、复习积压在收敛—— 比单纯的大数字多一层「在哪儿」。

实现：服务端聚合 op_log 按日聚合，前端在 .metric 里塞 <svg class="spark">。 sparkline 用 d3-shape-less 的 path 函数画，hover 显示当日数字。

06

回忆螺旋

新视图时间型

另一条时间型鸟瞰：全部记忆按时间排成对数螺旋， 中心 = 现在，越外越旧，半径 = log(天数差)， 色相 = kind，亮度 = 重要性。 比平面时间线更「物理」、更接近人脑做记忆模型的隐喻。

实现：把 engram_timeline 的列表数据拿来按 t 坐标 log-scale 排到极坐标上。 适合发现「很老但很重要的早期决策」「突然密集的新主题」。
