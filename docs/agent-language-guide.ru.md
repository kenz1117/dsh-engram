# Как ввести новый язык дворца — инструкция для агента (черновик)

**Черновик, только по-русски.** Это текст, который агент читает из плагина и переводит на язык
пользователя. Английская и китайская версии не сделаны намеренно: сначала проверяем содержание
на одном языке.

## Кому

Пользователю, чьего языка нет среди вшитых (`zh`, `en`). Окно первого запуска в этом случае
записывает дворцу настоящий код его языка (например `fr`) и говорит: «попросите агента вывести
инструкцию». Эта инструкция — то, что агент должен прочитать и выполнить вместе с человеком.

## Что важно понять до начала

1. **Язык дворца — данные, а не код.** Ничего пересобирать не нужно: язык объявляется файлом
   реестра, его тексты приходят файлами словарей.
2. **Смена языка и пересчёт баз — одно действие.** Человек выбирает язык, снимает предохранитель
   и нажимает «Выполнить». Всё это в одном окне (по умолчанию 30 секунд, настройка
   `palaceChangeWindowSec`). Раньше условия не выполняются — язык не меняется, базы не трогаются.
3. **Ничего не пишем руками в пакет плагина.** Правки живут в каталоге данных:
   `<dbDir>/registry/*.json` и `<dbDir>/i18n/*.txt` (по умолчанию `~/.dsh/engram`).

## Порядок

### 1. Узнать код языка

Код — первые две-три латинские буквы локали: `fr`, `de`, `pt`, `zh-Hans`. Проверьте, что такого
языка ещё нет: в панели «Обслуживание» список языков приходит из реестра.

### 2. Объявить язык в реестре

Файл `<dbDir>/registry/languages.json`; если его нет — создайте. Формат:

```json
{
  "languages": [
    { "code": "fr", "label": "Français", "builtin": false }
  ]
}
```

Строка этого файла заменяет строку с тем же кодом и добавляется, если кода ещё нет: полный список
поставки повторять не нужно. `builtin` — есть ли у плагина вшитые тексты; для нового языка всегда
`false`.

После этого язык виден и в списке языков дворца, и в переключателе языка интерфейса.

### 3. Привязать язык к модели

Файл `<dbDir>/registry/bindings.json` (слой пользователя):

```json
{
  "bindings": [
    { "language": "fr", "model": "Xenova/paraphrase-multilingual-MiniLM-L12-v2" }
  ]
}
```

Если для языка уже действует умолчание `*`, эта строка не нужна. Модель должна быть в каталоге
`registry/models.json` — иначе плагин скажет, что привязка не работает.

### 4. Завести словари и заполнить их

Словари — файлы `<dbDir>/i18n/<код>.txt` (служебные сообщения) и `<dbDir>/i18n/panel.<код>.txt`
(тексты панели). Пустой словарь — это файл с одним заголовком; отдельного «создать словарь» нет,
его создаёт первое сохранение.

Дальше — панель: «Обслуживание» → «Словарь» → выбрать набор → кнопка **«Перевести»**. Она
отправляет рабочей модели только те клетки, где перевода нет, и держит терминологию по уже
принятым парам. Заполнение идёт партиями, его можно остановить; файл меняет «Сохранить», а не
модель.

Что сказать человеку: словарь не обязан быть полным с первого раза. Нет строки — показывается
английский текст, плагин работает.

### 5. Сменить язык дворца собранным условием

Панель «Обслуживание» → блок «Язык дворца»:

1. выберите язык;
2. снимите предохранитель;
3. нажмите «Выполнить» — и всё это в пределах окна (по умолчанию 30 секунд с первого действия).

Окно истекло — выбор возвращается к языку, на котором стоят базы, предохранитель встаёт обратно.
Язык записывается в конфигурацию плагина, метки баз переписываются на новый язык, векторы
пересчитываются на модель нового языка. Всё это делает один запрос: раздельных «сначала язык,
потом базы» нет намеренно.

### 6. Проверить

- В карточке обслуживания язык дворца — новый, а рядом нет строки «применится после перезапуска».
- В таблице баз состояние у всех `normal`, чужих векторов и записей без вектора нет.
- Откройте любую запись: текст на новом языке, поиск находит по словам этого языка.

## Чего не делать

- Не менять файлы внутри пакета плагина: они перезапишутся обновлением.
- Не запускать пересчёт векторов вручную в обход условия: тогда язык и базы разъедутся, и
  дворец будет писать тексты на одном языке, а искать по векторам другого.
- Не выставлять язык дворца раньше, чем появился словарь: служебные надписи будут английскими,
  и человек решит, что язык не сработал.
