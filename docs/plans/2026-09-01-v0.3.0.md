# dsh-engram v0.3.0 实现计划（三期：Web 管理面板）

设计依据：`docs/design.md` 三期章节 + 已确认决策（**宿主静态页模式**：host webServer 服务 `/engram` 管理页与 `/api/engram/*` 数据接口，不走宿主 client 模块表——灵枢 /roleplay 同款、billing 的 host 路由样板）。

## 架构

- **API**（host 半，全部回环守卫：peer socket + Host 头 + 写操作 Origin/Content-Type 校验，billing `guardLoopback` 模式）：
  - `GET /engram` → 管理页（单文件 HTML，内联 CSS/JS，简体中文 UI）
  - `GET /api/engram/stats` → 两库统计合并
  - `GET /api/engram/list?scope&status&kind&q&limit&offset` → 分页列表（`q` 非空走混合检索；否则按过滤条件分页，含 archived/forgotten——管理视图要能看全部状态）
  - `GET /api/engram/review?id&scope` → 审计视图
  - `POST /api/engram/update`（id/scope/content/kind?/importance?）→ supersedes 取代链修正
  - `POST /api/engram/forget`、`POST /api/engram/restore`
  - `GET /api/engram/export?format=markdown|json&scope` → 全库导出文件流下载
- **store 扩展**：`list(filter)` 接口方法（动态 WHERE：scope/status/kind/子串 + limit/offset + 总数）。
- **页面**（原生 HTML/CSS/JS）：统计卡片行、过滤条（scope/status/kind/搜索框）、记忆列表（content、kind/status 徽章、importance/confidence 条、来源摘要、时间）、行操作（详情弹层 = review、编辑 = update 语义进取代链、遗忘/恢复）、导出按钮（markdown/json）、手动刷新。
- **组合测试**：加 `@deepseek-ai/dsh-host-webserver` 真实 webserver，HTTP 断言各端点 + 回环守卫 403。

## 任务

- **T3** 组合测试（真实 webserver + HTTP 断言）+ README + v0.3.0 提交。
