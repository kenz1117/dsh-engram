# dsh-engram v0.7.1 实现计划（UI 打磨 + 修复 + 上架准备）

在 v0.7.0 的「管理面板 zustand → hooks / 双库健康分 / 走廊鸟瞰 / 导览提案 / 翻新清单」基础上，本期只做收口：UI 布局打磨、typecheck 清理、隐私元数据交互、并补充上架到 dsh-market「AGI 架构探索」类目的文案与版本。

## 关键设计决策（实现前锁定）

1. **「管家日报」整体条作为 scope 切换的全局视图**——tabs 上方常驻、左右两区等高（规模 2×2 + 近 7 天 5 格），scope 跟随 Header 三宫格唯一切换器。删掉原来日报条标题行里重复的 scope chip + `ScopeChipRow` 组件 + 死 `scopeLabel` 词典键；Header 与 `observeScope` 局部 state 全部合并到全局 `scope`。两步到位：先把它从健康分卡顶部腾出来（v0.7.1 一开始），再做分组网格。
2. **信息类别聚簇（mainCol = 全局 + 动作类；sideCol = 回顾类）**——翻新卡（整改建议）从右列移到主列，插入检索台之后；右列剩导览提案 + 管家日志。这样走廊鸟瞰 + 翻新共享「对宫殿做什么」叙事，右列纯粹「已发生 / 拟发生」。
3. **设计令牌全面统一**——`--fs-tag: 10px` 新增；列表 / 骨架 / pill / segItem / viaChip / actScope / 空态魔法数（6px、10px、12px、13px 等）全部替换为 `--space-*` / `--radius-*` / `--fs-*`。删除无引用的 `.kpi` / `.teleItem` / `.scopeChip` 样式块。
4. **隐私元数据从脚注改为叹号徽标**——管家日报卡片标题行右侧叹号 + 11px 短标签「数据仅在本机聚合 · 不外传」，hover / 聚焦弹出 260-320px 长说明（覆盖 op_log 落库语义 + 重启清空）。这样告别「近 7 天本地聚合 · 不外传」占整行 + 上方分隔线。
5. **管家日志限高 280px + 内部滚动 + 底部 16px 渐隐 mask**——20 条满载约 700px+ 把观察页整列拉长，限高与走廊鸟瞰协调；padding-bottom 补偿 mask 带高，滚到底时最后一条完整可见，竖线（`.timeline::before`）随内容滚动属预期行为。
6. **窄屏防挤压 / 双列回落单列**——header 加 `flex-wrap` + `row-gap`；`.layout` / `.observeTop` / `.teleBar` 在 ≤960px 回落单列，侧栏取消 sticky 顺流排布。
7. **修复 typecheck / cordis API 迁移**——18 个既有错误清理：① `backup/tar-stream.ts` 缺 `Writable` 导入；② `backup/tar.ts` 未用变量 + readonly push 死代码；③ `CorridorMap.tsx` 的 `EdgeStyle.dash` 在 `exactOptionalPropertyTypes` 下报错；④ `EngramPanel.tsx` 的 `MemoryRow.scope` / `StatsPart.scope` / `ReviewBody` / `scope` 持久化 state 全部放宽三态（shared scope 之前 UI 已三宫格、类型层漏改）；⑤ cordis 移除 `session.events`，六处调用点统一换 `snapshotEvents()`，并补 `writeMirror` 之前未导入的 ReferenceError；⑥ `tests/{consolidation,mirror,rationale}.spec.ts` 三处漏字段（sourceSeq、outcome 条件展开、删多余 status）。
8. **dsh-market 上架**——`dsh-market` 数据源为社区维护的 awesome-dsh-plugin 清单，类目由作者自选无审核。本仓库目标类目：**AGI 架构探索**（dsh-engram 是记忆宫殿隐喻下的认知科学方法论重构 agent 长期记忆，符合该类目「agent 架构探索」叙事）。README 加 AGI 架构探索摘要与 keywords。

## 任务分解

- **T1 管家日报重构**：`TelemetryCard` → `TelemetryBar`（移到 tabs 上方、自拉 stats+telemetry 一次并行）；scope 跟随 Header；分组网格（左规模 2×2 / 右近 7 天 5 格）；叹号徽标嵌入标题行右侧。
- **T2 信息聚簇翻新**：RefurbCard 从 sideCol 移到 mainCol（检索台之后）；sideCol 剩导览 + 管家日志。
- **T3 设计令牌统一 + 清理**：`--fs-tag` 新增；列表/骨架/pill/segItem/actScope/viaChip/空态魔法数替换；删除无引用样式块。
- **T4 管家日志限高 + 渐隐**：`activityList` 280px + overflow + mask-image。
- **T5 窄屏断点**：header flex-wrap；layout/observeTop 单列化（合并到既有 960px 块）；teleBar flex-wrap。
- **T6 修复**：① tar-stream `Writable`；② tar.ts 未用变量与 readonly push；③ CorridorMap `dash` 允许 undefined；④ EngramPanel shared scope 类型链；⑤ session.events → snapshotEvents() ×6 + create.ts writeMirror 导入；⑥ tests 三处。
- **T7 上架**：README.md / README.en.md 加 AGI 架构探索摘要与关键词；package.json keywords 扩充；版本 bump 0.7.0 → 0.7.1；plan 落档；提交 + tag v0.7.1 + push + npm publish。

## 已查证的事实

- `Session.events` 在 cordis 当前版本已移除，正确访问是 `session.snapshotEvents()`，返回不可变事件快照数组（之前 5 处 + 1 处重试用法全部换）。
- `dsh-market` 入口为社区 PR 提交到 `awesome-dsh-plugin` 清单，类目自选无审核；`dsh-market/dsh-market` repo 渲染前端清单。仓库创建满 1 天门禁（`kenz1117/dsh-engram` 已建 >1 天，满足）。
